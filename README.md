# Personal Engineering Portfolio

This repository contains the source code for my personal engineering
portfolio website.

The portfolio highlights selected projects in modern C++ systems
programming, automotive software, and automation, along with links to
their respective GitHub repositories.

The site is intentionally simple and focused on content rather than
frameworks, serving as a central place to explore my work and background.

## What This Portfolio Showcases

- Modern C++ systems projects (C++17 / C++20)
- Automotive-oriented software design and tooling
- Clean ownership models and RAII-based design
- Factory patterns and production-style architecture
- Automation and validation utilities
